# Ursina Godot Level Editor
A godot plugin I made for my friend's game greed that interprets godot CSG boxes into basic levels (collections of platforms really) for ursina

Clone the repo and download the zip

Extract it into the addons folder of a new godot project

Enable the plugin

For 99.9999999875% percent of people, this is just code you can read for fun, if you want to make it work for any ursina project you gotta edit greed_exporter_dock.tscn and change it from writing Bricks to writing entities or something
